# Salvora Set Workshop

เว็บสำหรับวาดและตรวจ "ชุดเซ็ต" ของเกม (พื้น ผนัง ของติดผนัง ครัว โซนลูกค้า ตกแต่ง ของเล็ก รวม 45 ชิ้น)

- เปิดออนไลน์: https://sakagitnat.github.io/My-game/art-workshop/ (หรือเปิดไฟล์ `index.html` ในเบราว์เซอร์ ทำงานออฟไลน์ ไม่ส่งภาพขึ้นเซิร์ฟเวอร์)
- แท็บ 1: ดาวน์โหลดแม่แบบทั้งชุดเป็นภาพเดียว (1920 px หรือ 3840 px) วาดทับแล้วซ่อนเลเยอร์แม่แบบก่อนส่งออก
- แท็บ 2: อัปโหลดภาพที่วาด เว็บตัดเป็นชิ้น ตรวจ (พื้นต่อกันเนียนไหม ปลายเคาน์เตอร์/ผนังชนขอบไหม พื้นหลังโปร่งใสไหม) ลบพื้นหลังสีเดียวให้ได้ แล้วส่งออก ZIP ตามชื่อและโฟลเดอร์ที่เกมใช้
- แท็บ 3: จัดฉากจำลองร้านเล็กจากชิ้นที่ตัด ดูว่าเข้ากันไหม พร้อมสีเฉลี่ยของแต่ละชิ้นและรายการจุดที่ควรแก้
- รายการชิ้นทั้งหมดดู `docs/ART_SET.md`

สร้างด้วย `python3 tools/workshop/build.py` (แหล่งรายการ: `tools/workshop/items.py`, หน้าเว็บ: `tools/workshop/template.html`) ไฟล์ `set_template_*` เป็นแม่แบบที่ดาวน์โหลดได้โดยตรง
