# Salvora Set Workshop

เว็บสำหรับวาดและตรวจ "ชุดเซ็ต" ของเกม (พื้น ผนัง ของติดผนัง ครัว โซนลูกค้า ตกแต่ง ของเล็ก พื้นกลางแจ้งและขอบพื้น รวม 133 ชิ้น 5 แผ่น ตั้งแต่ของที่เกมใช้ตอนนี้ไปจนถึงไอคอนและตัวละคร)

- เปิดออนไลน์: https://sakagitnat.github.io/My-game/art-workshop/ (หรือเปิดไฟล์ `index.html` ในเบราว์เซอร์ ทำงานออฟไลน์ ไม่ส่งภาพขึ้นเซิร์ฟเวอร์)
- แท็บ 1: ดาวน์โหลดแม่แบบทีละแผ่น (1920 px หรือ 3840 px) พร้อมคำสั่งสำหรับ GPT ของแต่ละแผ่น วาดทับแล้วซ่อนเลเยอร์แม่แบบก่อนส่งออก
- แท็บ 2: เลือกแผ่นแล้วอัปโหลดภาพที่วาด เว็บตัดเป็นชิ้น ตรวจ (พื้นต่อกันเนียนไหม ปลายเคาน์เตอร์/ผนังชนขอบไหม พื้นหลังโปร่งใสไหม) ลบพื้นหลังสีเดียวให้ได้ แล้วส่งออก ZIP ตามชื่อและโฟลเดอร์ที่เกมใช้
- แท็บ 3: จัดฉากจำลองร้านเล็กจากชิ้นที่ตัด ดูว่าเข้ากันไหม พร้อมสีเฉลี่ยของแต่ละชิ้นและรายการจุดที่ควรแก้
- รายการชิ้นทั้งหมดดู `docs/ART_SET.md`

สร้างด้วย `python3 tools/workshop/build.py` (แหล่งรายการ: `tools/workshop/items.py`, หน้าเว็บ: `tools/workshop/template.html`) ไฟล์ `set_template_<แผ่น>_*_guide.png / _blank.png / _prompt.txt` เป็นแม่แบบที่ดาวน์โหลดได้โดยตรง
- ตัดแผ่นที่วาดเป็นไฟล์เกมจากบรรทัดคำสั่ง: `python3 tools/workshop/cut_sheet.py SHEET.png --sheet N [--skip id,id] [--report] [--dry]` (ผลเหมือน ZIP จากเว็บ) ชุดแรก (ชุด A, วาดโดย GPT) อยู่ใน `assets/td/`
