# ลำดับงานภาพและสเปกละเอียด (ฉบับล่าสุด)

คำสั่งของเจ้าของโปรเจค: **ทำฉากให้เสร็จก่อน แล้วค่อยทำระบบตัวละคร** เอกสารนี้บอกว่าภาพอะไรทำก่อน อะไรทำทีหลัง และสเปกของแต่ละอย่าง ใช้คู่กับ `docs/ASSETS.md` (กติกาไฟล์ทั่วไป: PNG โปร่งใส ชื่อไฟล์ตัวพิมพ์เล็กขีดล่าง สไตล์จิบิลายเส้นเข้มชุดเดียวกัน) ถ้าสเปกสองไฟล์ขัดกัน ให้ยึดไฟล์นี้

## วิธีทำงาน
- ทำทีละช่วง ตามลำดับ A → B → C ห้ามข้ามช่วง ภายในช่วงทำตามลำดับตัวเลข
- ส่งเป็น PR เข้า `main` จาก `gpt/visuals` ช่วงละ PR (หรือย่อยกว่านั้น) CI ต้องผ่าน (`tests/assets_check.gd` ตรวจชื่อ ขนาด มุมโปร่งใส) แล้วขอภาพเรนเดอร์ก่อน merge ตามเดิม
- **ชื่อไฟล์ตรงตามรายการ เกมจะแสดงภาพจริงแทนภาพที่โค้ดวาดชั่วคราวเองโดยไม่ต้องแก้โค้ด** (ส่วนที่ต้องให้ Claude เชื่อมโค้ดก่อนจะระบุไว้ในแต่ละข้อ)
- ภาพทั้งหมดในช่วงเดียวกันต้องใช้ชุดสี แสง (มาจากบนซ้าย) และความหนาเส้นขอบเดียวกัน ย่อลงเหลือขนาดในเกมแล้วเส้นขอบต้องยังเห็นชัด (ขนาดในเกมเล็กกว่าต้นฉบับ 7 ถึง 16 เท่า)

### A2. ผนังร้าน ในโฟลเดอร์ใหม่ `assets/walls/` (เกมเชื่อมโค้ดรอแล้ว)
ผนังเป็นชิ้นวางบนขอบช่อง **วาดเป็นมุมมองตรงด้านหน้า แบนๆ ไม่ต้องเป็นไอโซเมตริก** เกมจะบิดภาพลงบนผนังไอโซเมตริกเองและทำให้ผนังอีกด้านมืดลงเล็กน้อยเอง
| ไฟล์ | ขนาดผืนผ้าใบ | คืออะไร |
|---|---|---|
| `wall_plain_01.png` | **512×840** | ผนังเรียบ |
| `wall_door_01.png` | **512×840** | ผนังมีช่องประตู |
| `wall_low_01.png` | **512×112** | ผนังเตี้ย (ราวหรือกำแพงเตี้ย) |
กติกาสำคัญ:
1. **หนึ่งไฟล์กว้าง 2 ช่อง** ผืนผ้าใบกว้าง 512 = ผนัง 2 ช่อง ต่อกัน เกมใช้ครึ่งซ้ายสำหรับช่องแรกและครึ่งขวาสำหรับช่องที่สองสลับกัน ดังนั้นหน้าต่างหรือประตูควรวางกึ่งกลางภาพ กว้างได้ถึงประมาณ 60% ของความกว้าง
2. **ต่อซ้ายขวาไม่เห็นรอยต่อ**: ขอบซ้ายสุดของภาพต้องต่อเนื่องกับขอบขวาสุดของภาพ เมื่อวางไฟล์เดียวกันสองชิ้นเรียงกัน
3. สัดส่วนความสูง: 840 px แบ่งคร่าวๆ เป็นบัวผนังล่างประมาณ 90 px, ตัวผนัง, ขอบบนประมาณ 40 px ความสูงเตี้ยของ `wall_low` = 112 px ใส่ขอบบนเป็นแผ่นปิด
4. หน้าต่าง: กระจกโปร่งแสงได้ (ใช้ความโปร่งใสบางส่วน) เกมไม่วาดอะไรหลังกระจก ถ้าอยากให้เห็นข้างนอก ให้ทำกระจกทึบสีฟ้าอ่อนแทน
5. ช่องประตู: **พื้นที่ช่องประตูต้องโปร่งใสจริงตั้งแต่ขอบล่างของภาพ** ให้ผู้เล่นเห็นพื้นร้านผ่านช่อง ใส่กรอบประตูและคานบนเป็นส่วนของภาพ
6. ด้านล่างของภาพต้องเป็นขอบล่างของผนังพอดี (ไม่ต้องเว้นขอบโปร่งใสด้านล่าง) ผนังวางทับขอบช่องเต็มความกว้าง ไม่มีเงาตกพื้น
7. ทำเฉพาะ `_01` ตอนนี้ (ยังไม่มีการสุ่มหลายแบบ) ตัวตรวจ `assets_check` จะเช็กขนาด 512×840 และ 512×112

**ของติดผนัง (แยกจากผนัง ผู้เล่นตกแต่งได้)** ผนังเรียบ (`wall_plain_01`) ไม่มีหน้าต่าง หน้าต่าง โคมไฟ และภาพวาดเป็นภาพแยก ซ้อนทับบนผนังเรียบ ขนาด **256×840** (กว้าง 1 ช่อง สูงเท่าผนัง) พื้นโปร่งใส วาดเฉพาะของที่ติดผนัง ตำแหน่งตามแม่แบบ `docs/templates/tpl_wall_overlay_256x840.png`
| ไฟล์ (`assets/walls/`) | คืออะไร |
|---|---|
| `wdeco_window_01.png` | หน้าต่าง (เกมใช้แล้ว: ช่องผนังชนิด "หน้าต่าง" = ผนังเรียบ + ภาพนี้) |
| `wdeco_lamp_01.png` | โคมไฟติดผนัง (ยังไม่เชื่อมในเกม) |
| `wdeco_painting_01.png` | ภาพวาดติดผนัง (ยังไม่เชื่อมในเกม) |
ประตูยังเป็นชิ้นผนัง `wall_door_01` เพราะต้องเจาะช่องโปร่งใส

### A3. พื้นกลางแจ้งและพื้นร้าน ในโฟลเดอร์ `assets/tiles/` (เกมเชื่อมโค้ดรอแล้ว)
ขนาดและตำแหน่งเหมือน `tile_grass_01.png` ทุกประการ: ผืนผ้าใบ 1024×1024 ข้าวหลามตัดเต็มความกว้าง 1024 สูง 512 อยู่กึ่งกลางภาพพอดี มุมโปร่งใส

|---|---|
| `tile_road_dirt_01.png`, `_02`, `_03` | ถนนดินชนบท 3 แบบ (ร่องล้อ กรวด หญ้าริม) |

กติกาสำคัญ:
1. **ต่อกันทุกทิศไม่เห็นรอยต่อ** (เกมวางทีละช่องชิดกัน) ห้ามมีเส้นขอบหรือเงาที่ขอบข้าวหลามตัด ห้ามมีลายที่มุมซึ่งเมื่อต่อกันเห็นเป็นตาราง
2. **เกมสุ่มแบบต่อช่อง** ดังนั้นทุกแบบในชุดเดียวกันต้องผสมกันแล้วดูเป็นธรรมชาติ (ไม่ใช่ลายหมากรุก ถ้าอยากได้พื้นลายสลับสี ให้วาดเป็นลายที่ผสมแบบสุ่มแล้วสวย)
3. ทำเฉพาะ 3 กลุ่มนี้ก่อน ส่วนหญ้า ทราย ทะเล ที่มีอยู่ เกมวาดด้วยโค้ดแบบไล่สีต่อเนื่องไม่มีรอยต่ออยู่แล้ว ยังไม่ต้องแตะ

## ช่วง D: ตัวละครแบบชิ้นส่วน (ยังไม่ต้องเริ่ม ทำหลังฉากเสร็จและเจ้าของโปรเจคสั่ง)
เพื่อให้ผู้เล่น NPC และลูกค้าแต่งตัวและสุ่มรูปลักษณ์ได้ ภาพตัวละครจะเปลี่ยนจากรูปเต็มตัว เป็นชิ้นส่วนซ้อนเลเยอร์ นี่คือสเปกล่วงหน้าเพื่อให้วางแผนได้ (**อย่าเริ่มทำจนกว่าจะมีคำสั่ง**):
- ผืนผ้าใบ 1024×1024 เท่ากันทุกชิ้น ตัวฐานอยู่ตำแหน่งเดียวกับ `char_customer_01_se.png` และสเกลเดียวกัน ชิ้นส่วนทุกชิ้นวาดตามตำแหน่งนั้น เพื่อซ้อนกันได้พอดีโดยไม่ต้องจัดวาง
- 2 ท่า: ยืน (`stand`) และนั่ง (`sit`) หัน 1 ทิศ (`se`) ส่วน `sw` เกมพลิกภาพซ้ายขวาเอง ดังนั้นห้ามมีรายละเอียดที่ไม่สมมาตร (ข้อความ ตัวอักษร) ถ้าชิ้นไหนจำเป็นต้องไม่สมมาตรให้แจ้ง
- ชิ้นที่ต้องเปลี่ยนสีได้ (ผิว ผม เสื้อ กางเกง) **วาดเป็นสีกลางๆ สว่างค่อนไปทางเทา** ให้เกมคูณสีทับ ขอบเส้นสีน้ำตาลเข้มยังเข้มอยู่
- ชื่อไฟล์ `char_<ชิ้น>_<แบบ>_<ท่า>_se.png` เช่น `char_body_01_stand_se.png`, `char_hair_03_back_stand_se.png`, `char_hair_03_front_stand_se.png` (ผมแยกเลเยอร์หลังหัวกับหน้าหัว), `char_top_02_sit_se.png`, `char_bottom_01_stand_se.png`, `char_shoes_01_stand_se.png`, `char_face_02_stand_se.png` (สีหน้า), `char_acc_01_stand_se.png` (หมวด/เครื่องประดับ)
- ชุดแรกที่พอใช้: ตัวฐาน 1 แบบ, ผม 6, เสื้อ 6, กางเกงหรือกระโปรง 4, รองเท้า 2, หมวก/เครื่องประดับ 4, สีหน้า 3 อย่างละ 2 ท่า รวมประมาณ 50 ภาพ
- ลำดับซ้อน (ล่างขึ้นบน): ผมหลัง, ตัวฐาน, กางเกง, รองเท้า, เสื้อ, หน้า, ผมหน้า, เครื่องประดับ
- ท่าเดินยังไม่ทำ (เริ่มจากเลื่อนตัวโดยไม่ขยับขา)
