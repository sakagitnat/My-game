# รายการภาพที่ต้องใช้ — Are you hungry?

เอกสารนี้เป็นข้อกำหนดภาพสำหรับ GPT/Codex ที่ทำงานใน repo นี้ Claude รับผิดชอบโค้ดและระบบเกม GPT รับผิดชอบภาพ

## กติกาการทำงานร่วมกัน

- GPT/Codex แก้เฉพาะโฟลเดอร์ `assets/` และไฟล์นี้ ห้ามแก้โค้ดเกม (`main.gd`, `web/`, `tests/`) นอกจากตกลงกันก่อน
- Claude แก้โค้ดและอ่านภาพจาก `assets/` ผ่านชื่อไฟล์ในไฟล์นี้เท่านั้น ถ้าชื่อไฟล์ตรง เกมจะแสดงภาพจริงแทน placeholder โดยไม่ต้องแก้โค้ด
- ส่งงานเป็นชุด (เช่น หมวด tiles หนึ่งชุด) แยก branch หรือ commit ต่อชุด ไม่รวมทั้งโปรเจคใน commit เดียว
- ทำตามลำดับความสำคัญ P0 → P1 → P2 ห้ามข้ามไปทำ P2 ก่อน P0 ครบ

## สเปกไฟล์ (ทุกภาพ)

- รูปแบบ PNG พื้นหลังโปร่งใสจริง (ไม่ใช่พื้นขาวหรือลายหมากรุก)
- ขนาดต้นฉบับ 1024x1024 px วางวัตถุกึ่งกลางภาพ ชิดขอบล่าง เว้นขอบรอบ ๆ อย่างน้อย 5%
- วัตถุหนึ่งชิ้นต่อหนึ่งไฟล์ ไม่รวมหลายชิ้นในภาพเดียว ไม่มีเงาตกพื้นเป็นภาพแยก ให้มีเงาใต้วัตถุแบบนุ่มในไฟล์เดียวกัน
- มุมกล้อง isometric 2:1 เหมือนกันทุกภาพ แสงมาจากด้านบนซ้าย
- ชื่อไฟล์เป็นตัวพิมพ์เล็ก ใช้ขีดล่าง ตามรูปแบบ `หมวด_ชื่อ_เลขลำดับ.png` เช่น `deco_table_wood_01.png`
- ไอคอนใช้ 256x256 px ไม่ต้องเป็น isometric เป็นภาพตรงหน้า

ตำแหน่งภาพในเกม (ตัวเกมวางแบบนี้ ภาพต้องออกแบบให้ตรง):
- **tile:** รูปข้าวหลามตัดต้องเต็มความกว้างภาพ 1024 px สูง 512 px วางกึ่งกลางภาพพอดี
- **วัตถุ 1 ช่อง:** ฐานของวัตถุอยู่กึ่งกลางด้านล่างของภาพ ความกว้างวัตถุไม่เกิน ~90% ของภาพ ภาพถูกย่อ 1024 → 128 px

กริดเกม: 1 ช่อง = สี่เหลี่ยมข้าวหลามตัดสัดส่วน 2:1 ใช้ช่องละ 128x64 px ในเกม ผมจะย่อภาพต้นฉบับเอง ผู้สร้างภาพไม่ต้องคำนวณขนาด

## Prompt แม่แบบ (แปะต้นทุกครั้ง)

```
Cozy isometric 2D game asset, cute chibi anime style, soft cel shading with
clean dark-brown outlines, warm tropical island palette (sand, teak wood,
turquoise water, leafy greens, terracotta), light from top-left, 2:1 isometric
camera angle, single object centered and bottom-aligned, soft contact shadow
under the object, fully transparent background, no text, no watermark,
square 1024x1024 canvas.
Subject: <ใส่ชื่อวัตถุ>
```

ทุกภาพในชุดเดียวกันต้องใช้แม่แบบนี้เหมือนกันเพื่อให้สไตล์ไม่เพี้ยน ถ้าภาพชุดใดสไตล์ต่างจากชุดก่อน ให้ทำใหม่

## โครงสร้างโฟลเดอร์

```
assets/
  tiles/      พื้น ที่ดิน ทะเล
  buildings/  อาคาร โครงสร้างใหญ่
  restaurant/ เฟอร์นิเจอร์และอุปกรณ์ครัว
  farm/       พืช สัตว์ เครื่องแปรรูป
  deco/       ของตกแต่ง
  chars/      ตัวละคร
  icons/      ไอคอนสินค้า อาหาร ทรัพยากร
  ui/         ปุ่ม กรอบ HUD
  app/        ไอคอนแอป ภาพหน้าร้าน Play Store
```

## P1 — ขยายเนื้อหา

- **tiles:** ที่ดินขอบหน้าผา, ชายหาดต่อเนื่องน้ำ, ท่าเรือไม้ (`tile_pier_01`)
- **restaurant:** โต๊ะริมทะเลพร้อมร่ม, เตาอบ, ตู้เย็น, อ่างล้างจาน, เครื่องปั่น, ระเบียงไม้, ป้ายร้าน
- **buildings:** `bld_cottage_lv3`, `bld_staff_house_01` (บ้านพักพนักงาน), `bld_market_stall_01`
- **farm:** พืชเพิ่ม (ข้าวโพด, สตรอว์เบอร์รี, สมุนไพร) แบบ 4 สถานะ, ต้นไม้ผลไม้ (ส้ม มะพร้าว) แบบ 3 สถานะ, วัว/โรงนม, โรงโม่แป้ง, เตาอบขนมปัง, ที่ทำแยม, บ่อน้ำ, หุ่นไล่กา
- **chars:** ลูกค้าเพิ่มเป็น 8 แบบ, พนักงาน 4 ตำแหน่ง (พ่อครัว เด็กเสิร์ฟ คนงานฟาร์ม แคชเชียร์), ชาวประมง, ช่างไม้
- **icons:** อาหารรวม 16 จาน, วัตถุดิบเพิ่ม (นม เนย ชีส กุ้ง ผลไม้ ฯลฯ)
- **ui:** ไอคอนเมนูล่าง (คลัง เควส อัพเกรด พนักงาน ตลาด), ป้ายระดับ, กรอบการ์ดพนักงาน

## P2 — ตกแต่งและเมืองท่องเที่ยว

ของตกแต่ง 30 ชิ้นแรก (ชื่อไฟล์ `deco_*_01.png`):
- เฟอร์นิเจอร์: โซฟาหวาย, เก้าอี้ชายหาด, ม้านั่งไม้, เปลญวน, โต๊ะกลมริมสวน
- พื้นและผนัง: พรมสาน, ผนังไม้ไผ่, ผนังหินสีขาว, ม่านผ้าลินิน
- ต้นไม้และสวน: ต้นปาล์ม, พุ่มดอกไม้, กระถางต้นไม้, บ่อปลา, ก้อนหินตกแต่ง, ทางเดินกรวด
- รั้ว: รั้วไม้ขาว, รั้วไม้ไผ่, ประตูโค้ง
- แสงสว่าง: โคมไฟกระดาษ, ไฟสายระย้า, ตะเกียงตั้งพื้น, คบไฟชายหาด
- ของประดับ: ป้ายไม้ลอยน้ำ, เรือประมงจอด, ห่วงยาง, กระดิ่งลม, ธงราว, รูปปั้นเล็ก, ชั้นหนังสือ, ถังไม้

ภาพเมืองและเกาะ: ประภาคาร, เรือสินค้า, ท่าเรือซ่อมแล้ว, สะพานไม้, ศาลาริมหาด

## ภาพแอป (ทำท้ายสุด)

- `app/icon_512.png` ไอคอนแอป 512x512 (ไม่โปร่งใส พื้นเต็ม)
- `app/feature_1024x500.png` ภาพโปรโมตหน้า Play Store
- ภาพหน้าจอแคปเกมจริง ผมจะแคปจากเกมเองเมื่อพร้อม

## หมายเหตุสำหรับผู้สร้างภาพ

- ถ้าภาพที่สร้างได้พื้นหลังไม่โปร่งใส ให้ใช้เครื่องมือลบพื้นหลังก่อนบันทึก ห้ามส่งภาพพื้นขาว
- ภาพที่มีตัวหนังสือไม่ต้องใส่ ข้อความทั้งหมดผมเขียนในเกมเอง
- ตรวจเงื่อนไขการใช้ภาพเชิงพาณิชย์ของเครื่องมือที่ใช้สร้างก่อนขึ้น Play Store
