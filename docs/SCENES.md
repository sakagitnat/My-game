# โครงสร้างฉาก (แบบร่างการออกแบบ ยังไม่ได้ลงมือทำ)

บันทึกคำสั่งของเจ้าของโปรเจคเรื่องฉาก ส่วนที่เป็นข้อเสนอของ Claude มีป้ายกำกับไว้ ห้ามถือเป็นคำสั่งจนกว่าเจ้าของโปรเจคยืนยัน

## 1. ที่เจ้าของโปรเจคสั่งแล้ว
- เกาะทั้งเกาะเป็น **ภาพรวมสำหรับดูเท่านั้น เป็นงานอาร์ต** ไม่ใช่พื้นที่ที่เล่นในนั้น
- เล่นผ่าน **ฉากแยกกัน** แต่ละฉากมีขนาดของตัวเอง เหมือน Stardew ที่ลานฟาร์มด้านนอกกับในบ้านเป็นคนละแผนที่คนละขนาด
- ฉากหลัก: **ร้านอาหาร (ฉากด้านใน)**, **ฟาร์ม (ด้านนอก)**, **ตัวเมือง (ด้านนอก ผู้เล่นเดินได้ NPC เดินเอง)**
- เปลี่ยนฉากด้วยการ **เดินไปที่ขอบฉากหรือประตู**
- ฉากร้านอาหารเป็นห้องร้านอาหารจริง **ขนาดไม่ใหญ่มาก** มีพื้นกระเบื้อง ผนัง โต๊ะ โคมไฟ และอุปกรณ์ต่างๆ
- มุมมองยังเป็นไอโซเมตริก (ภาพอ้างอิงที่เจ้าของโปรเจคส่งมา: ห้องไอโซเมตริกแบบตัดผนังให้เห็นด้านใน เมืองไอโซเมตริกน่ารักลายเส้นเข้ม และร้านอาหารในเกมอย่าง Restaurant Story / My Café ที่มีผนังสองด้าน พื้นกระเบื้อง เคาน์เตอร์อุปกรณ์ตามผนัง ลูกค้านั่งโต๊ะ)
- ตัวละครแบบจิบิหัวโตตัวสั้นเรียบง่าย (ตัดสินแล้วใน Issue #8)

## 2. สิ่งที่ทำไว้แล้วและใช้ต่อได้
- ผังเกาะใน `scripts/core/island.gd` และภาพ `docs/island_layout.png` ใช้เป็นข้อมูลของแผนที่ภาพรวม บอกว่าสถานที่ไหนอยู่ตรงไหนบนเกาะ
- โค้ดชายฝั่งธรรมชาติ ใช้วาดแผนที่ภาพรวมได้
- ระบบร้านอาหาร (ลูกค้า สั่ง ทำ เสิร์ฟ ชื่อเสียง) และฟาร์ม ใช้ต่อได้ ไม่ต้องเขียนใหม่ แค่ย้ายไปอยู่ในฉากของตัวเอง

## 2.1 สิ่งที่เจ้าของโปรเจคสั่งเพิ่ม (ขั้นแรก: ฉากร้านอาหารกับกริดตกแต่ง)
- ร้านเริ่มต้นด้วยโครงสร้างอาคารของร้านอยู่แล้ว (พื้น ผนัง ประตู) ที่ดินรอบๆ ซื้อเพิ่มได้ แล้วตกแต่งเป็นอาคาร (ต่อเติมเป็นพื้นอาคาร) หรือเป็นพื้นที่ด้านนอกที่มีหญ้าก็ได้
- ร้านอยู่ **ติดริมทะเลด้านหนึ่ง และติดถนนชนบทอีกด้านหนึ่ง**
- เมื่อเข้าโหมดตกแต่ง (วางหรือย้ายของ) ต้องเห็น **กริด** เพื่อให้วางง่าย
- เปลี่ยนฉากด้วยการเดินไปขอบฉากหรือประตู (ขั้นต่อไป ตอนนี้ยังใช้ปุ่มสลับฉากชั่วคราว)

ทำแล้วในขั้นนี้: ฉากร้านอาหารแยกเป็นแผนที่ของตัวเอง 48x36 ช่อง ทะเลอยู่ด้านหลังร้าน ถนนดินชนบทอยู่ด้านหน้า มีแนวป่าล้อมขอบ ร้านเป็นห้องพื้นกระเบื้องมีผนังสองด้านพร้อมหน้าต่างและประตู (ภาพที่โค้ดวาดชั่วคราว รอ GPT) ที่ดินรอบร้านเป็นระเบียงริมทะเลและสวนซื้อได้ แตะที่ดินที่ซื้อแล้วเพื่อต่อเติมเป็นพื้นอาคาร (60 เหรียญ) หรือกลับเป็นพื้นโล่ง กริดแสดงตอนวางหรือย้ายของ ฉากฟาร์มยังเป็นแปลงที่ดินเดิม ยังไม่ทำ: ตัวละครเดินและประตู/ขอบฉาก แผนที่เกาะภาพรวมที่ผู้เล่นดูได้ ฉากเมือง

## 2.2 แผนที่เป็นข้อมูล และคำสั่งล่าสุดของเจ้าของโปรเจค
- เจ้าของโปรเจคต้องการ **ออกแบบแผนที่ทุกฉากเอง** และ **ทะเลติดฝั่งเดียวเท่านั้น** (ผังเกาะแบบที่ Claude ออกแบบไม่ถูกใจ)
- แผนที่แต่ละฉากเป็นข้อมูล JSON ใน `data/maps/<ฉาก>.json` (ชนิดพื้นรายช่อง ผนังบนขอบช่อง ต้นไม้และหินที่ตั้งอยู่ ของที่วางไว้ล่วงหน้า และชนิดของบล็อกที่ดิน `.` ล็อก `B` ขาย `S` เป็นของผู้เล่นตั้งแต่เริ่ม) อ่านผ่าน `SceneLayout` และ `MapStore` ค่าเริ่มต้นสร้างจาก `tools/gen_default_maps.py`
- นอกขอบแผนที่เป็นพื้นมืด ไม่ใช่ทะเล ทะเลมีเฉพาะช่องน้ำที่วาดไว้ในแผนที่ (ขอบแผนที่ที่เป็นน้ำจะต่อเนื่องเป็นทะเลออกไป)
- **โหมดแต่งแผนที่ (ทำแล้ว)**: เมนู > Edit map แล้วเลือกเครื่องมือที่แถบล่าง
  - พื้น: หญ้า ทราย น้ำ ถนน ทางปู พื้นกระเบื้อง ดิน (พู่กัน 1 ถึง 4 ช่อง) ชายฝั่งน้ำโค้งอัตโนมัติ
  - ผนัง: ผนัง หน้าต่าง ประตู ผนังเตี้ย วางบนขอบช่อง (ผนังสูงที่ด้านหน้าจะบังของด้านหลัง ใช้ผนังเตี้ยด้านหน้า)
  - ต้นไม้ ก้อนหิน พุ่มไม้ และของในฉาก (วางล่วงหน้าให้เป็นของฟรี)
  - บล็อกที่ดิน: ล็อก / ขาย / เริ่มต้น (เป็นของผู้เล่นตั้งแต่เริ่ม)
  - ลบของ ลบผนัง ย้อนกลับ/ทำซ้ำ เปลี่ยนขนาดแผนที่ทีละบล็อก (3 ถึง 16 บล็อก) สลับระหว่างฉากร้านอาหารกับฟาร์มได้ในโหมดแต่ง
  - บันทึกเก็บไว้ในเครื่อง (ใช้เล่นต่อได้ทันที) คัดลอก/วางแผนที่เป็นข้อความ เพื่อส่งให้ Claude บันทึกเป็นแผนที่เริ่มต้นของเกม และกลับไปแผนที่เดิมของเกมได้
  - ตอนเข้าโหมดแต่ง ของที่ผู้เล่นวางไว้ในฉากนั้นจะหาย (เงิน เลเวล โกดังยังอยู่)
- ผังเกาะภาพรวม (`docs/island_layout.png`) เป็นแค่ภาพอ้างอิงเก่า ไม่ได้ใช้ในเกมแล้ว

## 2.3 แผนที่ร้านอาหารเริ่มต้นตามที่เจ้าของโปรเจคสั่ง (ปรับรอบที่ 2)
ทะเลอยู่ที่ขอบล่างซ้ายของแผนที่ (ด้านหน้าใกล้ผู้เล่น) ถนนดินพาดผ่านขอบบนขวาชิดขอบแผนที่ ร้านอยู่ใกล้มุมบน ประตูอยู่ที่ผนังด้านเหนือหันเข้าหาถนน มีทางปูเชื่อม แผนที่ใหญ่ขึ้นเป็น 72x54 ช่อง (12x9 บล็อก) ส่วนที่เหลือเจ้าของโปรเจคปรับเองได้ในโหมดแต่งแผนที่

## 3. ข้อเสนอของ Claude (ยังไม่ยืนยัน)
- ฉากเป็นข้อมูล: แต่ละฉากมี id ขนาดกริด ชนิด (ในร่ม/กลางแจ้ง) ตำแหน่งประตูหรือขอบทางออก และปลายทาง เซฟแยกต่อฉาก
- ตัวละครผู้เล่นปรากฏในทุกฉากและเดินตามที่แตะ (ภาพชั่วคราวจนกว่า GPT จะวาด) ชนทางออกแล้วเปลี่ยนฉาก
- ฉากร้านอาหาร: ห้องมีขนาดเริ่มต้นเล็ก ผนังสองด้านและประตูด้านหน้า วางโต๊ะ เตา โคมไฟ ของตกแต่งได้ ไม่มีระบบซื้อที่ดินเป็นบล็อกในร้าน ห้องขยายด้วยการอัปเกรดขนาดห้อง (ยังไม่ยืนยัน)
- ฉากฟาร์ม: ยังซื้อที่ดินเป็นบล็อกเหมือนเดิม
- ประตูร้านอาหารไปที่ฉากเมือง (ร้านอยู่ติดลานเมืองตามผัง) ขอบฟาร์มเชื่อมฉากเมืองทางตะวันตก
- ทำทีละขั้น: (1) โครงฉากและตัวละครเดิน (2) ฉากร้านอาหารด้านใน (3) ฉากฟาร์ม (4) ฉากเมือง (5) แผนที่เกาะภาพรวม

## 4. ภาพที่ฝั่งกราฟิกต้องทำเพิ่ม (ยังไม่ต้องเริ่มจนกว่าจะแจ้ง)
ร้านอาหารด้านใน: พื้นกระเบื้อง ผนังและหน้าต่าง ประตู โต๊ะและเก้าอี้ โคมไฟ เคาน์เตอร์ เตา และอุปกรณ์ครัว ของตกแต่ง
ด้านนอก: ต้นไม้ ก้อนหิน พุ่มไม้ พืช เล้าไก่ รั้ว อาคารเมือง
ตัวละคร: ผู้เล่น (แยกเลเยอร์สำหรับแต่งตัว) NPC ลูกค้า
อื่นๆ: ภาพแผนที่เกาะภาพรวม

## ปรับล่าสุด: ร้านกับฟาร์มเป็นแผนที่เดียว (เจ้าของโปรเจคตัดสินใจ)
- แผนที่หลัก `data/maps/restaurant.json` (72x54 ช่อง, `area: "any"`) มีทั้งร้าน (บล็อกเริ่มต้น 4 บล็อกฝั่งซ้าย ติดถนนด้านบน) และฟาร์ม (บล็อกเริ่มต้น 4 บล็อกฝั่งขวา) ทะเลอยู่มุมล่างซ้าย ที่ดินรอบๆ ซื้อได้ 31 บล็อก
- ปุ่มสลับฉากร้าน/ฟาร์มซ่อนเมื่อแผนที่เป็น `any` ร้านค้ารายการซื้อแสดงของทุกอย่างบนแผนที่เดียว
- ฉากฟาร์มเดิม (`data/maps/farm.json`) ยังอยู่ในระบบแต่ไม่ถูกใช้ในเกมจริง (เทสต์ยังใช้)
- ภายในอาคารของคนอื่นในเมืองทีหลังใช้ฉากแยกเดินเข้าประตู

## วัตถุในแผนที่ (`objects`)

ตำแหน่งและขนาดของ `objects` ในไฟล์แผนที่นับเป็น "หน่วย" ครึ่งช่อง (ดู `docs/ART_TOPDOWN.md` หัวข้อกริดวางของ) ส่วน `tiles`, `walls`, `obstacles` และที่ดินยังนับเป็นช่อง
