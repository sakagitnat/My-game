# โครงสร้างฉาก (แบบร่างการออกแบบ ยังไม่ได้ลงมือทำ)

บันทึกคำสั่งของเจ้าของโปรเจคเรื่องฉาก ส่วนที่เป็นข้อเสนอของ Claude มีป้ายกำกับไว้ ห้ามถือเป็นคำสั่งจนกว่าเจ้าของโปรเจคยืนยัน

## 1. ที่เจ้าของโปรเจคสั่งแล้ว
- เกาะทั้งเกาะเป็น **ภาพรวมสำหรับดูเท่านั้น เป็นงานอาร์ต** ไม่ใช่พื้นที่ที่เล่นในนั้น
- เล่นผ่าน **ฉากแยกกัน** แต่ละฉากมีขนาดของตัวเอง เหมือน Stardew ที่ลานฟาร์มด้านนอกกับในบ้านเป็นคนละแผนที่คนละขนาด
- ฉากหลัก: **ร้านอาหาร (ฉากด้านใน)**, **ฟาร์ม (ด้านนอก)**, **ตัวเมือง (ด้านนอก ผู้เล่นเดินได้ NPC เดินเอง)**
- เปลี่ยนฉากด้วยการ **เดินไปที่ขอบฉากหรือประตู**
- ฉากร้านอาหารเป็นห้องร้านอาหารจริง **ขนาดไม่ใหญ่มาก** มีพื้นกระเบื้อง ผนัง โต๊ะ โคมไฟ และอุปกรณ์ต่างๆ
- มุมมองยังเป็นไอโซเมตริก (ภาพอ้างอิงที่เจ้าของโปรเจคส่งมา: ห้องไอโซเมตริกแบบตัดผนังให้เห็นด้านใน เมืองไอโซเมตริกน่ารักลายเส้นเข้ม และร้านอาหารในเกมอย่าง Restaurant Story / My Café ที่มีผนังสองด้าน พื้นกระเบื้อง เคาน์เตอร์อุปกรณ์ตามผนัง ลูกค้านั่งโต๊ะ)
- ตัวละครแบบจิบิหัวโตตัวสั้นเรียบง่าย (ตัดสินแล้วใน Issue #8)

## 2. สิ่งที่ทำไว้แล้วและใช้ต่อได้
- ผังเกาะใน `scripts/core/island.gd` และภาพ `docs/island_layout.png` ใช้เป็นข้อมูลของแผนที่ภาพรวม บอกว่าสถานที่ไหนอยู่ตรงไหนบนเกาะ
- โค้ดชายฝั่งธรรมชาติ ใช้วาดแผนที่ภาพรวมได้
- ระบบร้านอาหาร (ลูกค้า สั่ง ทำ เสิร์ฟ ชื่อเสียง) และฟาร์ม ใช้ต่อได้ ไม่ต้องเขียนใหม่ แค่ย้ายไปอยู่ในฉากของตัวเอง

## 3. ข้อเสนอของ Claude (ยังไม่ยืนยัน)
- ฉากเป็นข้อมูล: แต่ละฉากมี id ขนาดกริด ชนิด (ในร่ม/กลางแจ้ง) ตำแหน่งประตูหรือขอบทางออก และปลายทาง เซฟแยกต่อฉาก
- ตัวละครผู้เล่นปรากฏในทุกฉากและเดินตามที่แตะ (ภาพชั่วคราวจนกว่า GPT จะวาด) ชนทางออกแล้วเปลี่ยนฉาก
- ฉากร้านอาหาร: ห้องมีขนาดเริ่มต้นเล็ก ผนังสองด้านและประตูด้านหน้า วางโต๊ะ เตา โคมไฟ ของตกแต่งได้ ไม่มีระบบซื้อที่ดินเป็นบล็อกในร้าน ห้องขยายด้วยการอัปเกรดขนาดห้อง (ยังไม่ยืนยัน)
- ฉากฟาร์ม: ยังซื้อที่ดินเป็นบล็อกเหมือนเดิม
- ประตูร้านอาหารไปที่ฉากเมือง (ร้านอยู่ติดลานเมืองตามผัง) ขอบฟาร์มเชื่อมฉากเมืองทางตะวันตก
- ทำทีละขั้น: (1) โครงฉากและตัวละครเดิน (2) ฉากร้านอาหารด้านใน (3) ฉากฟาร์ม (4) ฉากเมือง (5) แผนที่เกาะภาพรวม

## 4. ภาพที่ฝั่งกราฟิกต้องทำเพิ่ม (ยังไม่ต้องเริ่มจนกว่าจะแจ้ง)
ร้านอาหารด้านใน: พื้นกระเบื้อง ผนังและหน้าต่าง ประตู โต๊ะและเก้าอี้ โคมไฟ เคาน์เตอร์ เตา และอุปกรณ์ครัว ของตกแต่ง
ด้านนอก: ต้นไม้ ก้อนหิน พุ่มไม้ พืช เล้าไก่ รั้ว อาคารเมือง
ตัวละคร: ผู้เล่น (แยกเลเยอร์สำหรับแต่งตัว) NPC ลูกค้า
อื่นๆ: ภาพแผนที่เกาะภาพรวม
