# Salvora: ออกแบบระบบเกม

ร้านอาหารริมทะเลของแมวพ่อครัว ปลูกวัตถุดิบในสวนข้างร้าน ทำอาหาร เสิร์ฟลูกค้าสัตว์ แล้วเอาเงินไปขยายร้าน

## วงจรหลัก (ทำได้แล้ว)

```
ปลูก (แตะแปลงว่าง) ─► เก็บเกี่ยว (แตะแปลงสุก) ─► วัตถุดิบเข้าโกดัง
        ▲                                              │
        │                                              ▼
 ซื้อแปลง/โต๊ะ/เตาเพิ่ม ◄── เหรียญ + XP + ชื่อเสียง ◄── ลูกค้าสั่ง ─► แตะลูกค้า = ทำอาหาร ─► แตะอีกครั้ง = เสิร์ฟ
```

- **ลูกค้า** เดินเข้าร้านตอนร้านเปิด นั่งที่โต๊ะ มีการ์ดเมนูลอยเหนือหัว บอกว่าต้องทำอะไรต่อ ("แตะเพื่อทำ" / "กำลังทำ..." / "พร้อม แตะเสิร์ฟ" / "ขาด ข้าวสาลี x1") มีแถบความอดทน เขียว → ส้ม → แดง ถ้ารอนานเกินจะเดินออกและชื่อเสียงลด
- **แตะลูกค้า** ถ้าอาหารพร้อมจะเสิร์ฟทันที ถ้ายังไม่พร้อมจะเริ่มทำบนเตาที่ว่าง ไม่ต้องไปหาปุ่มในแผงข้าง
- **แตะเตา** เปิดเมนูอาหารทั้งหมด พร้อมจำนวนวัตถุดิบที่มี/ที่ต้องใช้ ทำล่วงหน้าเก็บไว้ที่เคาน์เตอร์ได้ (6 จาน)
- **ทิป** ยิ่งเสิร์ฟเร็วยิ่งได้มาก (สูงสุด 25% ของราคา)
- **ชื่อเสียง** +1 ต่อการเสิร์ฟ ทำให้ลูกค้ามาถี่ขึ้น

## เริ่มเกมใหม่ (ทำได้แล้ว)

เปิดเกมครั้งแรกเล่นได้ทันที ร้านมีเตา 1 โต๊ะ 2 สวนมีแปลง 4 แปลง (ข้าวสาลีใกล้สุก 2 แปลง) โกดังมีข้าวสาลี 4 กำ เวลาเริ่ม 9:00 ร้านเปิดพอดี

## กลางวัน กลางคืน (ทำได้แล้ว)

หนึ่งวันในเกม = 12 นาทีจริง ร้านเปิด 9:00-21:00 (ตั้งเองได้) ตอนร้านปิดมีปุ่ม **"นอนถึง 9:00"** ข้ามช่วงที่ไม่มีลูกค้า พืชยังโตตามเวลาจริงเหมือนเดิม การนอนจึงไม่ได้ช่วยให้พืชโตเร็วขึ้น

## วางของ (ปรับแล้ว)

กดซื้อจากร้านค้า → ของโปร่งใสโผล่กลางจอ → **ลากด้วยนิ้ว** ไปวางตรงไหนก็ได้ (ลากที่ตัวของ = ย้ายของ, ลากที่อื่น = เลื่อนกล้อง) หรือแตะพื้นตรงที่ต้องการ → กด "วาง"

## แผนต่อไป

1. **ตกปลาที่ท่าเรือ** แตะท่าเรือ → มินิเกมกดจังหวะ → ได้ปลา → เมนูปลาย่าง ซุปปลา (เข้ากับธีมริมทะเล)
2. **กระดานออเดอร์ส่งของ** เรือมาจอดรับของเป็นชุด (เช่น ข้าวสาลี 5 + ไข่ 3) ได้เหรียญก้อนใหญ่ ให้ผลผลิตส่วนเกินมีที่ไป
3. **เมนูและวัตถุดิบเพิ่ม** แครอท สตรอว์เบอร์รี นม (วัว) แป้ง (โรงโม่) → ขนมปัง เค้ก
4. **ลูกค้าพิเศษ** มาตามช่วงเวลา (นกฮูกตอนกลางคืน) สั่งเมนูแพง ให้ทิปเยอะ
5. **ตกแต่งร้าน** ของตกแต่งเพิ่มเสน่ห์ร้าน → ลูกค้ามาเยอะขึ้น/ทิปมากขึ้น
6. **เสียงและเพลง** + รางวัลรายวัน
