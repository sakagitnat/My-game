# Salvora: เทียบกับเกมแนวเดียวกัน และสิ่งที่ยังขาด

ข้อมูลเทียบอ้างอิงจากเกมที่ค้นข้อมูลได้และที่ทราบทั่วไป: Hay Day ([Roadside Shop](https://hayday.fandom.com/wiki/Roadside_Shop), [Truck](https://hayday.fandom.com/wiki/Truck), [กลยุทธ์เลเวล/XP](https://www.player.one/hay-day-strategy-guide-tips-tricks-leveling-collecting-coins-and-wheating-creamsugar-527050)), Township ([ภาพรวมระบบ](https://en.wikipedia.org/wiki/Township_(video_game)), [วิเคราะห์](https://www.deconstructoroffun.com/blog/2020/10/13/how-playrix-township-became-a-billion-dollar-game)) และเกมร้านอาหาร/คาเฟ่ (Cooking Diary, Cafe Master Story, My Cafe)

## รูปแบบ UI ที่เกมแนวนี้ใช้ตรงกัน
- แตะวัตถุเพื่อใช้งานทันที ไม่มี "โหมดเครื่องมือ": แตะแปลงที่สุกเก็บเกี่ยวเลย แตะแปลงว่างเปิดเมนูเลือกพืช
- ซื้อของจากปุ่ม Shop แล้ววางด้วยเงาตัวอย่างสีเขียว/แดงและปุ่มยืนยัน/ยกเลิก
- ย้ายและขายคืนวัตถุได้ทุกชิ้น
- HUD บนสุดมีเลเวล/XP/เหรียญ ปุ่มหลักอยู่มุมล่าง
- ซื้อที่ดินมีกล่องยืนยันราคา
- มีข้อความลอยบอกผลรับ (+1 ข้าวสาลี, +XP) และประกาศเลเวลอัป

## ลำดับที่แนะนำ
1. **ออเดอร์ส่งของ + ร้านริมทาง**: ให้ผลผลิตมีที่ไป ให้เหรียญ/XP เป็นจังหวะ (ทำเร็ว ใช้ระบบเดิม)
2. **ร้านอาหารจริง**: ลูกค้า ออเดอร์อาหาร ทำอาหารจากวัตถุดิบฟาร์ม (แกนของเกมตามเนื้อเรื่อง)
3. **โรงงานแปรรูป**: ทำให้เมนูอาหารมีหลายระดับ
4. **เสียง + tutorial + รางวัลรายวัน**: ก่อนปล่อย Play Store
5. **เพชร เควสพัฒนาเมือง พนักงาน ตกแต่ง**
6. **ภาพจริงทั้งหมด** (ทำคู่ขนานกับ GPT ตาม `docs/ASSETS.md`)

## การตัดสินใจของเจ้าของโปรเจค (เรื่องตัวเมืองแบบ Stardew)
- ทำแกนร้านอาหารกับฟาร์มให้เรียบร้อยก่อน แล้วค่อยวางแผนตัวเมืองกับเจ้าของโปรเจค
- ภาพและโค้ดวาดของตัวเมือง รอ GPT
- การซื้อของ (ตอนวางแผนเมือง): แบบผสม ของที่มีบนเกาะซื้อได้ทันที ของที่ต้องมาจากนอกเกาะสั่งแล้วรอเวลาจริง
