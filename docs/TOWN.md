# ระบบตัวเมือง (แบบร่างการออกแบบ ยังไม่ได้ลงมือทำ)

เอกสารนี้บันทึกสิ่งที่เจ้าของโปรเจคตัดสินใจแล้ว และข้อเสนอของ Claude ที่รอยืนยัน ส่วนที่เป็นข้อเสนอมีป้ายกำกับไว้ ห้ามถือเป็นคำสั่งจนกว่าเจ้าของโปรเจคยืนยัน

## 1. สิ่งที่เจ้าของโปรเจคตัดสินใจแล้ว
- ทำแกนร้านอาหารและฟาร์มให้เรียบร้อยก่อน แล้วค่อยทำตัวเมือง (ร้านอาหารเสร็จแล้ว ฟาร์มยังมีของที่ต้องตกลงต่อ)
- ตัวเมืองเป็นโซนที่เดินได้: แตะแล้วตัวละครของผู้เล่นเดิน และ NPC เดินเอง
- ภาพและโค้ดวาดของตัวเมืองรอ ChatGPT (Claude ไม่วาด placeholder)
- การซื้อของแบบผสม: ของที่มีบนเกาะซื้อได้ทันที ของที่ต้องมาจากนอกเกาะสั่งแล้วรอเวลาจริง
- ลำดับอาคารและบทบาทในข้อ 2 ตรงกับที่เจ้าของโปรเจคคิดไว้
- ผู้เล่นมีระบบแต่งตัว
- เข้าเกมครั้งแรกให้ตั้งชื่อตัวละครและชื่อร้าน แล้วตัวละครอื่นเรียกด้วยชื่อแทนสรรพนาม (ทำแล้ว: หน้าตั้งชื่อ เก็บในเซฟ และข้อความต้อนรับ)
- โทนของตัวละคร: ร่าเริง เฟรนลี่
- บทพูดและข้อความที่เกี่ยวกับผู้เล่นต้องเป็นกลางทางเพศ (ไม่ใช้ ครับ/ค่ะ/ผม/ฉัน กับผู้เล่น) และบทพูดภาษาไทยกับอังกฤษต้องมีความหมายตรงกัน
- NPC ปลดล็อกสูตรอาหาร เมล็ด และอุปกรณ์ใหม่ผ่านเควสหรือความสัมพันธ์ (เก็บไว้ทำตอนหลัง)
- ระบบความสัมพันธ์/โรแมนซ์: ทำตอนหลัง ไม่อยู่ในรอบแรก

## 2. สถานที่บนเกาะ (เจ้าของโปรเจคยืนยัน ผ่านสรุปของ GPT ใน Issue #8)
ท่าเรือ (รวมจุดขายปลาและอาหารทะเล ไม่มีตลาดปลาแยก) / ร้านอาหารของผู้เล่น / ฟาร์มของผู้เล่น / ลานกลางเมืองกับศาลาชุมชน (บอร์ดเควส ข่าว เทศกาล) / ร้านชำ / ร้านเสื้อผ้า / โรงช่างไม้ / โรงเรียน / คลินิกเล็ก / บ้านชาวเกาะ / รีสอร์ตเก่า (มีตั้งแต่เริ่ม แต่ซบเซา ต้องซ่อมและพัฒนา) / ประภาคาร / ป่าสำรองและลานโล่ง (เก็บไว้สำหรับอัปเดตอนาคต)

โรงโม่และร้านขนมพักไว้สำหรับอัปเดตภายหลัง ไม่อยู่ในเมืองชุดแรก ยังไม่สรุป: เงื่อนไขปลดล็อกและการซ่อม, จำนวนบ้าน, กลไกคลินิก/โรงเรียน/ประภาคาร

## 2.1 ผังเกาะ (Claude ออกแบบตามคำสั่งเจ้าของโปรเจค รอยืนยัน)
เกาะเดียว พื้นที่เดียว ยังเป็นมุมไอโซเมตริก (แยกฉากได้ภายหลังถ้าใหญ่เกินไป) รูปร่างชายฝั่งเป็นธรรมชาติ ไม่เป็นบล็อก ภาพผังอยู่ที่ `docs/island_layout.png`

หลักการจัด: คนอยู่รวมกันเป็นย่าน บางหลังอยู่ห่างออกไปเล็กน้อยแต่ไม่ไกล และเว้นพื้นที่สำรองไว้
- ย่านเมืองอยู่กลางเกาะ: ลานกลางเมือง ร้านชำ ร้านเสื้อผ้า โรงช่างไม้ คลินิก โรงเรียน อยู่รอบลานเดียวกัน บ้านชาวเกาะอยู่ติดทางทิศตะวันออกของลาน
- ร้านอาหารอยู่ติดลานเมือง ฟาร์มอยู่ถัดไปทางตะวันตก ผู้เล่นเริ่มด้วยบล็อกร้านกับบล็อกฟาร์มที่ติดกัน ซื้อที่ดินเพิ่มได้เฉพาะบล็อกร้านอาหารกับฟาร์ม
- ท่าเรืออยู่ริมอ่าวทางใต้ ห่างจากลานประมาณ 3 บล็อก รีสอร์ตเก่าอยู่ชายหาดตะวันออกเฉียงใต้ ห่างจากเมืองประมาณ 3 บล็อก ประภาคารอยู่บนแหลมทางตะวันออกเฉียงเหนือ มีบ้านพักผู้ดูแลอยู่ใกล้ๆ บ้านพักอีกหลังอยู่ห่างออกไปทางเหนือ
- ป่าสำรองอยู่ทางเหนือและตะวันตกเฉียงเหนือ มีที่โล่งสำรองสำหรับอัปเดตอนาคตอีก 3 แห่งรอบเกาะ
- ผังเป็นข้อมูลใน `scripts/core/island.gd` (ป้ายพื้นที่ของแต่ละบล็อก และรูปชายฝั่ง) ปรับได้โดยไม่แก้โค้ดส่วนอื่น

(ข้อเสนอ ยังไม่ยืนยัน) ระดับหมู่บ้าน 1 ถึง 5 ขึ้นเมื่อสร้างอาคารครบชุดและส่งของให้ผู้ใหญ่บ้าน แต่ละระดับเปิดอาคาร ชนิดลูกค้า และเพดานเลเวลของพืช/เมนู/ที่ดิน อาคารเมืองสร้างด้วยเหรียญ + ไม้/หิน + ผลผลิต และใช้เวลาก่อสร้างจริง

## 3. เควส 4 ชนิด (ข้อเสนอ ยังไม่ยืนยัน)
1. ส่งของ: เอาผลผลิตหรือไข่จากโกดังไปส่ง
2. ร้าน: เสิร์ฟเมนู X จำนวน N จาน หรือทำชื่อเสียงให้ถึงระดับหนึ่ง
3. ก่อสร้าง/ถางที่: สร้างอาคาร ถางสิ่งกีดขวาง ซื้อที่ดินบล็อกใหม่
4. ส่วนตัวของ NPC: ปลดตามความสนิท (ทำตอนหลัง)

เควสเป็นข้อมูลล้วนใน `data/` เพิ่มเควสได้โดยไม่แก้โค้ด

## 4. ตัวละคร (ข้อเสนอ ชื่อเป็นชื่อชั่วคราว ปรับให้ตรงกับสถานที่ที่ยืนยันแล้ว ยังไม่ยืนยันตัวละคร)
บุคลิกรวมของทุกคนคือร่าเริง เป็นกันเอง

| ตัวละคร | อาคาร | บทบาท | ปลดล็อกภายหลัง |
|---|---|---|---|
| กัปตัน | ท่าเรือ | พาผู้เล่นมาเกาะ รู้จักโลกภายนอก | เมล็ดหายากจากนอกเกาะ วัตถุดิบนำเข้า |
| ผู้ใหญ่บ้าน | ลานกลางเมือง/ศาลา | ต้อนรับผู้เล่น ให้เควสหลัก | ระดับหมู่บ้าน ของตกแต่งเมือง |
| เจ้าของร้านชำ | ร้านชำ | รู้ข่าวทุกอย่าง | เมล็ดและของใช้เพิ่ม |
| ช่างไม้ | โรงช่างไม้ | ฝีมือดี ใช้ไม้หินที่ถางมา | อุปกรณ์ครัวใหม่ ขยายโกดัง |
| เจ้าของรีสอร์ตเก่า | รีสอร์ตเก่า | อยากให้รีสอร์ตกลับมาคึกคัก | ลูกค้ากลุ่มพิเศษเมื่อซ่อมแล้ว |
| พ่อค้าปลา | ท่าเรือ (จุดขายปลา) | จับปลาตอนเช้า ขายตอนสาย | ปลาและอาหารทะเล |
| หมอประจำเกาะ | คลินิกเล็ก | รู้สมุนไพรพื้นบ้าน | สมุนไพรและสูตรอาหารสุขภาพ |
| ช่างตัดเสื้อ | ร้านเสื้อผ้า | แต่งตัวให้ผู้เล่น | ชุดและเครื่องประดับ |
| ครู | โรงเรียน | เด็กๆ บนเกาะ | (ยังไม่กำหนด) |

ตัวละครรอง: นักท่องเที่ยวประจำที่กลับมาซ้ำ 2 ถึง 3 คน (มีชื่อและเมนูโปรด) ใช้ลูกค้าในร้านเป็นฐาน

## 5. ตัวละครผู้เล่น
- ตั้งชื่อตัวละครและชื่อร้านตอนเริ่มเกม (`GameState.player_name`, `restaurant_name`) บทพูดของ NPC ใช้ชื่อแทนสรรพนาม
- มีระบบแต่งตัว
- ผลต่อโค้ด (Claude): เก็บค่าสรรพนามและรายการชุดที่เป็นเจ้าของ/สวมใส่ในเซฟ และข้อความที่พูดถึงผู้เล่นต้องไม่ผูกกับเพศ ตามที่เจ้าของโปรเจคสั่ง: เขียนประโยคให้เป็นกลางทั้งสองภาษา และไทย/อังกฤษมีความหมายตรงกัน (ไม่ต้องแยกข้อความตามสรรพนาม) ข้อความที่มีอยู่ใน `data/strings.json` ตรวจแล้วว่าเป็นกลางอยู่แล้ว
- ผลต่อภาพ (ChatGPT): ตัวละครผู้เล่นต้องแยกเลเยอร์ผม ใบหน้า เสื้อ กางเกง รองเท้า เครื่องประดับ เพื่อสลับชุดได้ รายละเอียดสเปกจะแจ้งใน Issue #8 เมื่อถึงเวลาทำ

## 6. สิ่งที่ยังไม่ได้ตัดสินใจ
- รายชื่อตัวละครในข้อ 4 ตรงกับที่ต้องการไหม (ตัดหรือเพิ่มได้)
- โรแมนซ์เฉพาะบางตัวละครหรือทุกคน (ข้อเสนอคือเฉพาะบางคน และเริ่มจากระบบความสนิทธรรมดาก่อน)
- ระบบแต่งตัว: ได้ชุดจากไหน (ซื้อ รางวัลเควส NPC ขายชุด)
- ส่วนที่เหลือของฟาร์ม (โรงแปรรูป สัตว์/ต้นไม้เพิ่ม พนักงาน) ที่ต้องทำก่อนเริ่มตัวเมือง
