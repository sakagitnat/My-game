# ทดลอง: ภาพพิกเซลจากโมเดล 3D

สร้างของเป็นโมเดล 3D ง่าย ๆ ใน Blender ด้วยโค้ด เรนเดอร์จากมุมกล้องเดียวกับเกม แล้วแปลงเป็นพิกเซลอาร์ตด้วยพาเลตต์ของเกม (`tools/pixelart/palette.py`) ผลอยู่ที่ `assets/td/art_workshop/pilot/render3d/` เป็นชิ้นทดลอง ยังไม่ได้ใช้ในเกม

ทำไมลอง: ทุกชิ้นอยู่ในโลกเดียวกัน (1 หน่วย Blender = 1 ช่อง = 32 px, ความสูงเป็นบล็อก) สัดส่วนจึงตรงกันเสมอ และภาพแต่ละทิศ (หน้า ข้าง หลัง) กับท่าเดินได้จากการหมุนหรือขยับโมเดลเดิม ไม่ต้องวาดใหม่

## ขั้นตอน

```sh
uv venv -p 3.11 .bpyenv && uv pip install -p .bpyenv/bin/python bpy pillow   # ครั้งแรกครั้งเดียว (Blender เป็นโมดูล Python)
.bpyenv/bin/python tools/render3d/render.py /tmp/raw     # เรนเดอร์ใหญ่ 8 เท่า (ราว 10 วินาทีทั้งชุด)
python3 tools/render3d/pixelize.py /tmp/raw              # ย่อเป็น 32 px ต่อช่อง ใช้สีจากพาเลตต์ ใส่เส้นขอบ
python3 tools/render3d/compare.py                        # ภาพเทียบกับชิ้นที่วาดด้วยโค้ด และห้องจำลองสองแบบ
```

## ค่าที่ตั้งไว้

- กล้อง orthographic ก้ม 22 องศา: ลึก 1 ช่องเห็นผิวบน 12 px เท่าชิ้นที่วาดมือ ความสูงยืดด้วย 1/cos(22) ให้ 1 บล็อก = 32 px พอดี
- แสงมาจากซ้ายบน ไม่มีเงาตกพื้น (เกมวาดเงาเอง) ขอบล่างของภาพ = ขอบหน้าของช่องที่ของกิน
- ขนาดภาพตาม `docs/ART_SET.md`: โต๊ะ 48x32, เตา 48x40 (ข้าง 32x56, หลัง 48x40), เก้าอี้ 32x32, ตัวละคร 32x64
- แต่ละชิ้นใช้สีได้เฉพาะกลุ่มของมัน (`FAMILIES` ใน `pixelize.py`) เส้นขอบใช้สีเข้มสุดของกลุ่มสีนั้น

## เพิ่มชิ้นใหม่

เขียนฟังก์ชันสร้างโมเดลใน `render.py` (หันหน้าเข้าหากล้องที่ y = 0 บนพื้นที่ w x d ช่อง) แล้วเพิ่มแถวใน `JOBS` พร้อมทิศและขนาดภาพ ถ้าใช้โมเดลจากที่อื่น (เช่น Tripo) นำเข้าไฟล์ glTF ในฟังก์ชันนั้นแทนการสร้างจากกล่อง
