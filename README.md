# Tiny Tavern — เกมร้านอาหารต้นแบบ

เกม Godot 4.6.3 แบบออฟไลน์ มุมมองเฉียง ใช้ภาพวาดด้วยโค้ดต้นฉบับ ยังไม่มีภาพ AI หรือแอนิเมชันเดิน และยังไม่ใช่เกมพร้อมจำหน่าย

## วิธีเล่น

- กด SOUP, BREAD หรือ JUICE เพื่อทำอาหารฟรีครั้งละหนึ่งอย่าง
- แตะตัวลูกค้าที่สั่งอาหารตรงกับของที่ทำเสร็จเพื่อเสิร์ฟ
- รับเงิน 18/14/12 เหรียญต่อเมนู ลูกค้ารอได้ 45 วินาที
- ซื้อ Faster kitchen ราคาเริ่มต้น 60 เหรียญเพื่อทำอาหารเร็วขึ้น
- เงิน จำนวนที่เสิร์ฟ และระดับครัวบันทึกอัตโนมัติ อาหารและลูกค้าเริ่มใหม่เมื่อเปิดเกม

## ทดสอบบนมือถือ Android โดยไม่ใช้คอม

1. เปิดแท็บ **Actions** บน GitHub แล้วเลือก **Build Android demo**
2. เปิดรายการบิลด์ล่าสุดที่เป็นสีเขียว
3. เลื่อนลง **Artifacts** และดาวน์โหลด **tiny-tavern-android** (ต้องล็อกอิน GitHub)
4. แตก ZIP บนมือถือ Android แล้วเปิด `tiny-tavern.apk`
5. อนุญาตติดตั้งแอปจากแหล่งนี้เมื่อ Android ขอ แล้วเล่นในแนวนอน

ถ้าบิลด์เป็นสีแดง ให้ส่งลิงก์รายการบิลด์เพื่อแก้ไข ไม่ควรถือว่า APK สร้างสำเร็จจน workflow ผ่าน

APK นี้ลงบน Android เท่านั้น iPad ใช้อ่านโค้ด/สั่งงาน/จัดการ GitHub ได้

## ระบบบิลด์ฟรี

GitHub Actions ใช้โควตาของบัญชี โดยเฉพาะ repository ส่วนตัว หากต้องการไม่เสียเงิน ให้ตรวจ Billing และตั้งงบ Actions เป็น 0 ปิดการคิดค่าบริการส่วนเกิน โควตาฟรีไม่ใช่การบิลด์ไม่จำกัด

## สำหรับนักพัฒนา

เปิด `project.godot` ด้วย Godot 4.6.3 หรือทดสอบระบบหลักด้วย:

```sh
godot --headless --path . --script tests/smoke.gd
```

ก่อนทำเวอร์ชันขึ้น Google Play ต้องเพิ่ม release signing ด้วยคีย์ถาวรของเจ้าของเกม, export AAB, ทดสอบอุปกรณ์จริง, กำหนด target API ตามนโยบายปัจจุบัน และเตรียมข้อมูลหน้าร้าน APK debug นี้ใช้คีย์ทดสอบใหม่ในแต่ละบิลด์ ถ้าติดตั้งเวอร์ชันใหม่แล้วลายเซ็นไม่ตรง ต้องถอนการติดตั้งเวอร์ชันเก่าก่อน (เซฟเกมจะหาย)

## ขอบเขตต้นแบบ

ยังไม่มีเส้นทางเดิน พนักงาน วัตถุดิบหลายชนิด เสียง เกมบาลานซ์เต็มรูปแบบ หรือภาพระดับตัวอย่างต้นฉบับ

## เวอร์ชันเว็บสำหรับ iPad / Safari

เพิ่มเกม HTML Canvas ใน `web/` ใช้ระบบเล่นแบบเดียวกับต้นแบบ Godot แต่เป็นเวอร์ชัน JavaScript แยก ไม่ใช่ไฟล์ Godot export โหลดเบา ไม่มี WebAssembly หรือ WebGL และไม่ต้องติดตั้ง APK

แตะเมนูเพื่อทำอาหาร แล้วแตะลูกค้าหรือปุ่มเสิร์ฟ เซฟเงิน/จำนวนเสิร์ฟ/ระดับครัวใน localStorage ของเบราว์เซอร์ ลูกค้าและอาหารเริ่มใหม่เมื่อเปิดเกม เวลาหยุดเมื่อสลับแท็บ การล้างข้อมูลเว็บไซต์จะลบเซฟ เวอร์ชันเว็บและ APK ใช้เซฟแยกกัน

### Cloudflare Workers ที่เชื่อม GitHub ไว้แล้ว

ใน Workers & Pages → `my-game` → Settings → Build ตั้งค่า:

- Repository: `sakagitnat/My-game`
- Production branch: `main`
- Root directory: ราก repo (เว้นว่างหรือ `/` ตาม UI)
- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`

ไฟล์ `wrangler.jsonc` ระบุ static assets directory เป็น `./web` แล้ว ไม่มี backend หรือ secrets ที่ต้องตั้งค่า กด Retry build / Deploy หลังบันทึกการตั้งค่า จากนั้นเปิด URL สาธารณะใน Overview ซึ่งลงท้ายด้วย `workers.dev` ผ่าน Safari URL หน้าจัดการ `dash.cloudflare.com` ไม่ใช่ URL เกม

หากใช้ **Cloudflare Pages** แทน Workers: Framework preset `None`, Build command เว้นว่าง, Build output directory `web` และ branch `main` URL จะลงท้ายด้วย `pages.dev`

ตรวจสอบบน iPad จริงหลัง deploy: ทำอาหาร → แตะเสิร์ฟ → รับเงิน → โหลดหน้าใหม่เพื่อดูเซฟ → หมุนหน้าจอ หากขึ้น build error ส่ง log มาให้ตรวจ ไม่ต้องส่ง API token ในแชต

### ทดสอบเว็บบนเครื่องพัฒนา

```sh
npm run build
npm test
python3 -m http.server 8080 --directory web
```

โค้ดผ่านการทดสอบระบบหลักแล้ว แต่ยังต้องทดสอบ Safari บนอุปกรณ์จริงและตรวจผล deployment ของบัญชีเจ้าของเว็บ
