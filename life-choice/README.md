# ชะตาแห่งอาณาจักร

เกมเลือกทางชีวิตแนวแฟนตาซี เริ่มจากอายุ 5 ปี เลือกจุดเริ่มต้นได้ 4 แบบ แล้วตัดสินใจทุกปีจนจบชีวิต

## วิธีเล่น

- เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร
- แต่ละปีอาจมีเหตุการณ์ให้เลือก หรือเป็นปีที่เงียบสงบ
- ตัวเลือกที่มีการทดสอบจะทอย d20 บวกโบนัสจากค่าสถานะและโชค ต้องได้ตามค่า DC ที่แสดง
- สุขภาพลดลงตามอายุ ถ้าเหลือ 0 ชีวิตจะจบลง อายุครบ 100 ปีก็จบเช่นกัน

## ไฟล์

- `engine.js` ตรรกะของเกม ไม่มี DOM
- `app.js` และ `index.html` หน้าจอและการแสดงผล
- `engine.test.cjs` ทดสอบตรรกะ

ทดสอบด้วย:

```sh
node --test life-choice/engine.test.cjs
```
