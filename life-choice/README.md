# ชะตาแห่งอาณาจักร

เกมเลือกทางชีวิตแนวแฟนตาซี ตั้งชื่อและเลือกต้นกำเนิด แล้วตัดสินใจไปตลอดชีวิตตั้งแต่วัยเยาว์จนวัยชรา

## วิธีเล่น

- เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งหรือบิลด์
- ปีที่ไม่มีเหตุการณ์จะผ่านไปเอง แตะแผงข้อความเพื่อเร่งเวลา
- ตัวเลือกที่มีการทดสอบจะบอกโอกาสสำเร็จเป็นเปอร์เซ็นต์ (ทอย d20 บวกโบนัสจากค่าสถานะและโชค)
- สุขภาพลดลงตามอายุ เหลือ 0 เมื่อไรชีวิตก็จบ จบแล้วได้ฉายาตามค่าที่โดดเด่น ฉายาที่เคยได้ถูกเก็บไว้ในเบราว์เซอร์

## ภาพและเสียง

- ทุกฉากวาดด้วยโค้ดใน `scene.js` ไม่มีไฟล์ภาพ มี 18 ฉาก เช่น หมู่บ้าน ป้อมปราการ หอคอยเวทย์ สุสาน ถ้ำคริสตัล ท่าเรือ
- ฉากมีหลายชั้นเลื่อนแบบพารัลแลกซ์ มีหมอก แสงอาทิตย์ ไฟ หิ่งห้อย ฝน กลีบดอกไม้ มังกรบิน และพลุ
- เสียงสังเคราะห์สดใน `audio.js` (ดนตรีพื้นหลังและเสียงประกอบ) กดปุ่มลำโพงเพื่อปิดเสียง

## ไฟล์

- `engine.js` ตรรกะของเกม ไม่มี DOM
- `scene.js` ตัววาดฉาก
- `audio.js` เสียง
- `app.js` และ `index.html` หน้าจอและลำดับการเล่น
- `engine.test.cjs` ทดสอบตรรกะ และตรวจว่าทุกเหตุการณ์ชี้ไปที่ฉากที่มีอยู่

ทดสอบด้วย:

```sh
node --test life-choice/engine.test.cjs
```

เพิ่มเหตุการณ์ใหม่: ใส่ใน `EVENTS` ของ `engine.js` พร้อม `title` และ `scene` ที่มีอยู่ใน `SCENES` ของ `scene.js`
