# ชะตาแห่งอาณาจักร

เกมเลือกทางชีวิตแนวแฟนตาซี ตั้งชื่อและเลือกต้นกำเนิด แล้วตัดสินใจไปตลอดชีวิตตั้งแต่วัยเยาว์จนวัยชรา ทุกการเลือกส่งผลต่อเรื่องราวในอนาคตและตอนจบ

## วิธีเล่น

- เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งหรือบิลด์
- ปีที่ไม่มีเหตุการณ์จะผ่านไปเอง แตะแผงข้อความเพื่อเร่งเวลา
- ตัวเลือกที่มีการทดสอบจะบอกโอกาสสำเร็จเป็นเปอร์เซ็นต์ (ทอย d20 บวกโบนัสจากค่าสถานะและโชค)
- ตัวเลือกบางทางต้องมีทองหรือค่าสถานะถึงเกณฑ์ ถ้าไม่ถึงจะล็อกไว้และบอกเหตุผล

## ระบบเกม

- **เส้นเรื่องต่อเนื่อง** การเลือกจะทิ้งร่องรอยไว้ แล้วเปิดเหตุการณ์ตามมาในภายหลัง เช่น
  - ช่วยมังกรน้อยตอนเด็ก → มังกรกลับมาให้ขี่ → ศึกเหนือเมฆา
  - ขโมยไข่มังกร → แม่มังกรตามมาทวงแค้น
  - เป็นทหาร → รบชายแดน → ได้เป็นอัศวิน → ก่อกบฏขึ้นเป็นกษัตริย์
  - เรียนเวทย์ → คัมภีร์ต้องห้าม → พิธีแห่งความเป็นอมตะ
  - ร่วมก๊กโจร → ปล้นคลังหลวง หรือติดคุกแล้วต้องหาทางหนี
  - แหวนดำจากสุสาน → เสียงกระซิบในความฝัน
- **อาชีพ 10 แบบ** ทหาร อัศวิน จอมเวทย์ พ่อค้า นักผจญภัย โจรป่า หมอยา ฤๅษี กษัตริย์ ผู้ขี่มังกร แต่ละอาชีพให้ผลทุกปีและมีเหตุการณ์เฉพาะทาง
- **ครอบครัว** รักแรก แต่งงาน มีลูกได้ถึงสามคน ลูกโตแล้วออกเดินทาง คู่ชีวิตล้มป่วย และหลานในวัยชรา
- **เหตุการณ์ 59 เรื่อง** บางเรื่องเกิดซ้ำได้ (ตลาดนัด วงพนัน กวีพเนจร)
- **ความตายฉับพลัน** บางการเลือกที่เสี่ยงอาจจบชีวิตทันที เช่น ถูกประหาร ตายในคุก ตายกลางสนามรบ
- **ตอนจบ 35 แบบ** แต่ละแบบมีฉาก คำจารึก และคำใบ้ในหน้ารวมตอนจบ ตอนจบที่ค้นพบถูกเก็บไว้ในเบราว์เซอร์

## ภาพและเสียง

- ทุกฉากวาดด้วยโค้ดใน `scene.js` ไม่มีไฟล์ภาพ มี 23 ฉาก เช่น หมู่บ้าน ป้อมปราการ หอคอยเวทย์ สนามรบ คุกใต้ดิน ประตูมิติ ท้องฟ้าเหนือเมฆ
- เสียงสังเคราะห์สดใน `audio.js` กดปุ่มลำโพงเพื่อปิดเสียง

## ไฟล์

- `story.js` เนื้อเรื่องทั้งหมด: ต้นกำเนิด อาชีพ เหตุการณ์ ตอนจบ (คำอธิบายรูปแบบข้อมูลอยู่หัวไฟล์)
- `engine.js` กฎของเกม ไม่มี DOM
- `scene.js` ตัววาดฉาก
- `audio.js` เสียง
- `app.js` และ `index.html` หน้าจอและลำดับการเล่น
- `engine.test.cjs` ทดสอบกฎ ตรวจว่าข้อมูลเนื้อเรื่องเชื่อมกันครบ และจำลองการเล่นหลายร้อยชีวิต

ทดสอบด้วย:

```sh
node --test life-choice/engine.test.cjs
```

เพิ่มเหตุการณ์ใหม่: ใส่ใน `EVENTS` ของ `story.js` พร้อม `title` และ `scene` ที่มีอยู่ใน `SCENES` ของ `scene.js` ถ้าเหตุการณ์ต้องใช้ธงใน `when` ต้องมีตัวเลือกอื่นที่ `set` ธงนั้น ไม่อย่างนั้นการทดสอบจะแจ้งเตือน
